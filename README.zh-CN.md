# OPD Speed Run

[English](README.md)

**固定模型、固定数据、固定硬件、固定训练时间。**

OPD Speed Run 在统一计算预算下比较在线蒸馏（On-Policy Distillation，OPD）算法：给定一个固定的大教师，小学生在三小时内能提升多少？

当前赛道采用 **Qwen3-1.7B ← Qwen3-4B**，评测单轮数学和代码。我们在共同协议下复现已有方法，比较相同资源预算内最终 checkpoint 的表现。

> **发布进度：** 当前发布结果与实验协议，后续开放训练代码、评测工具、配置清单和复现产物。

## 当前结果

结果快照：**2026 年 10 月 17 日**。7 个训练配方已完成固定预算运行和全部四组评测。单位为百分比，粗体表示该列当前最高观测值。

| 算法 / 配方 | Math500 | AIME 2024 | AIME 2025 | LiveCodeBench v6¹ |
|:--|--:|--:|--:|--:|
| 初始学生（未训练） | 73.35 | 14.38 | 10.42 | 16.43 |
| OPD | 74.85 | 15.42 | 14.17 | 16.71 |
| ExOPD λ=1.1 | 75.35 | 15.83 | 13.96 | 16.43 |
| ExOPD λ=1.25 | 73.35 | 14.58 | 13.96 | **17.29** |
| Binary OPD | 74.45 | 15.63 | 12.92 | 16.43 |
| IW-OPD | 75.40 | **17.08** | **14.79** | 16.29 |
| TA-OPD (tail-aware) | **75.55** | 15.63 | **14.79** | 16.57 |
| LSPD | 75.25 | 13.33 | 13.33 | **17.29** |

¹ LiveCodeBench v6 成绩采用冻结的 **175 题子集**。

分数通过多次采样回答的平均正确率估计 **pass@1**。每个配方完成 **1 次训练，seed=42**；跨训练 seed 的排名稳定性待验证。

**结果概览：** IW-OPD 在 AIME 2024 领先；tail-aware TA-OPD 在 Math500 领先，AIME 2025 与 IW-OPD 并列；ExOPD λ=1.25 和 LSPD 在代码上并列领先，同时呈现数学成绩上的取舍。领先幅度较小：TA-OPD 比 IW-OPD 多答对 3/2,000 条 Math500 回答，代码榜首比普通 OPD 多答对 4/700 条。

ExOPD λ=1.25 采用公开推荐设置，λ=1.1 作为额外对照，两组成绩分别报告。

## 固定预算协议

| 项目 | 当前赛道 |
|:--|:--|
| 学生 | Qwen3-1.7B，每次从相同原始 HF 权重开始 |
| 教师 | 冻结的 Qwen3-4B，外部更大教师 |
| Thinking 模式 | 教师和学生均为 non-thinking |
| 训练数据 | 同一份基于 DeepMath 的 56,107 条 prompt-only 数据 |
| 硬件 | 单节点，16 × ZW810E PPU，每卡 96 GB |
| 时间限制 | 从 launcher 启动起计 10,800 秒，包含初始化和检查 |
| 资源分配 | Actor 8 卡、rollout 6 卡、教师 2 卡 |
| 训练 batch | 256 个 prompt，每题采样 1 条回答 |
| 训练采样 | Temperature=1.0，top-p=1.0，关闭 top-k |
| 训练长度 | 最大回答 8,192 tokens，上下文 32,768 tokens |
| 优化器 | Adam，固定学习率 1e-6，无 warmup，seed=42 |
| Loss 归约 | 每条回答内部按有效 token 取均值，再对回答取均值 |
| Checkpoint 选择 | 截止时间前最后一个完整保存的 checkpoint |

每次正式运行分配 **48 PPU 卡时**。资格验证、调试、失败尝试和最终评测的成本分别统计。设备利用率随采样、评分和更新阶段变化。

我们固定公共实验条件，保留各方法自身的目标函数和算法专属参数，并记录从作者默认设置适配到共同协议的改动。

## 评测协议

所有 checkpoint 共用冻结的提示词、解码设置、评分逻辑和题目 ID，按上述时间预算规则选择 checkpoint。

| 评测集 | 题数 | 每题采样数 | Temperature | Top-p | 最大回答 tokens |
|:--|--:|--:|--:|--:|--:|
| Math500 | 500 | 4 | 0.7 | 0.95 | 8,192 |
| AIME 2024 | 30 | 16 | 0.7 | 0.95 | 8,192 |
| AIME 2025 | 30 | 16 | 0.7 | 0.95 | 8,192 |
| LiveCodeBench v6 固定子集 | 175 | 4 | 1.0 | 1.0 | 16,384 |

每个 checkpoint 共评测 **3,660 条回答**。数学上下文上限为 10,240 tokens，代码为 24,576；评测 seed=20261014。代码通过执行测试判分。格式错误和截断回答保留在原始评测样本中。

## 复现检查

正式运行前，候选需要通过真实反向传播、完整 batch 更新、checkpoint 恢复一致性、数据游标连续性、导出重加载及同轨迹重打分检查。训练入口在资源分配前强制校验登记配置。资格记录将每项结果与实际验证的运行环境和配置绑定。

当前赛道为 ZW810E 上的 Qwen3-1.7B ← Qwen3-4B，预算三小时。数据审计覆盖精确去重；语义和预训练数据污染尚未审计。
