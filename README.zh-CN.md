# OPD Speed Run

**作者：Kai Ruan** · [English](README.md)

在固定数据、师生模型和 **16 × ZW810E PPU（96 GB/卡）、3 小时**预算内，比较开源教师到学生的能力迁移方法。数学、单轮代码和多轮 Agentic 三个赛道分别训练、分别报告结果。

**结果更新：2026-10-19。** 数学 13 个配方、代码 4 个配方完成评测。当前先开放 README，代码与复现产物后续发布。

## 比较口径

- **分数：** 百分比，采样平均正确率（pass@1 估计）；每个配方目前一次训练，seed=42。粗体为列内最高观测值。
- **评测：** Math500 每题 4 次采样，AIME 各每题 16 次；LCB v6¹ 使用冻结的 175 题子集、每题 4 次；HumanEval+ 164 题、MBPP+ 378 题，各每题 4 次，使用固定版本的官方 EvalPlus。格式错误与截断保留在分母中。
- **公平性：** 同赛道锁定数据及字段权限、师生初始权重、卡资源、时间、n、学习率、采样参数和正式评测。当前数学/代码训练 n=1、学习率 1e-6、temperature=1、top-p=1、关闭 top-k。
- **算法空间：** 允许 SFT、在线/离线蒸馏、RL、阶段组合、教师示范、缓存与回放；全部计入相同预算。保留有依据的算法专属差异，不引入外部数据或免费预训练 checkpoint；不适用的参数记为不适用。
- **计费与选点：** 从 launcher 启动计时，包含初始化、检查和训练各阶段；选择截止前最后完整保存的 checkpoint。调试、资格验证和最终评测另计。多轮使用共享沙箱池，环境排队、执行与清理计入预算，共享池拥塞需报告。

数学当前各项领先者不同；代码赛道 ExOPD λ=1.1 的三项代码成绩最高。单训练 seed 的小幅差异尚不能证明稳定排名。Lightning OPD 和 ULD 尚无正式成绩。
